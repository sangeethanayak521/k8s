Creating & Running a Python File in Linux

Use the Linux command line and the built-in nano text editor

Step 1: Open Terminal & Create File

In Linux, you don't need heavyweight IDEs to get started. Open your terminal emulator and create a new Python script using the nano editor:

bash - terminal
user@linux:~$ nano script.py

Write your Python code inside:

GNU nano - script.py
print("Hello from Linux!")

Step 2: Save, Exit & Execute

Nano provides keyboard shortcuts displayed at the bottom of the screen:

1. Save (WriteOut):
Ctrl + O → Enter
2. Exit nano:
Ctrl + X

Run with the python3 interpreter:

Terminal Execution
user@linux:~$ python3 script.py
Hello from Linux!

Printing & Math Calculations

The print() function and Python's 7 arithmetic operators

The print() function displays whatever you put inside the parentheses. You can print plain text, direct arithmetic calculations, or combine both by separating items with commas.

math_demo.py 
# Basic printing
print("Hello, World!")

# Math operators
print("Addition (10 + 5):", 10 + 5)             # +  adds
print("Subtraction (10 - 5):", 10 - 5)          # -  subtracts
print("Multiplication (10 * 5):", 10 * 5)       # *  multiplies
print("Division (10 / 3):", 10 / 3)             # /  divides (always returns float)
print("Floor Division (10 // 3):", 10 // 3)     # // divides and drops decimal
print("Modulus / Remainder (10 % 3):", 10 % 3)  # %  gives only remainder
print("Exponent / Power (2 ** 3):", 2 ** 3)     # ** raises to the power (2³)

Variables, Data Types & type()

How Python stores data in memory and automatically figures out types

int Integer

Whole numbers without decimals (positive or negative).

age = 25
float Floating Point

Numbers containing decimal points for precision.

price = 19.99
str String

Text sequences wrapped in double or single quotes.

name = "Alice"
bool Boolean

Binary truth conditions: exactly True or False.

is_online = True
types_demo.py 
city = "Bengaluru"      # String
item_count = 12         # Integer
temperature = 28.5      # Float
is_raining = False      # Boolean

# Printing variables directly
print(city)
print(item_count)

# Checking types using type()
print("city is:", type(city))
print("item_count is:", type(item_count))
print("temperature is:", type(temperature))
print("is_raining is:", type(is_raining))

💡 Dynamic Typing: In Python, you do not write int age = 25 like in Java/C++. Python checks the value on the right side of = and assigns the data type automatically!

Getting User Input: input()

Pausing script execution to accept keyboard input from the user

⚠️
Crucial Beginner Rule

The input() function always reads whatever the user types as a string (text). If you want to do arithmetic with numbers entered by the user, you must convert them using int() or float()!

input_demo.py 
# 1. Text input (kept as string)
user_name = input("Enter your name: ")
print("Hello,", user_name)

# 2. Number input (converted using int)
num1 = int(input("Enter first number: "))
num2 = int(input("Enter second number: "))

total = num1 + num2
print("The sum is:", total)

Comparison Operators

Evaluate conditions and always return True or False (Booleans)

Operator Meaning Example Code Result
> Greater than 10 > 5 True
< Less than 10 < 5 False
>= Greater than or equal to 10 >= 10 True
<= Less than or equal to 7 <= 6 False
== Equal to (checks equality) 5 == 5 True
!= Not equal to (checks if values differ) 5 != 3 True
comparison_demo.py 
x = 15
y = 20

print("x > y :", x > y)    # Is 15 greater than 20? -> False
print("x < y :", x < y)    # Is 15 less than 20? -> True
print("x >= 15:", x >= 15) # Is 15 greater than or equal to 15? -> True
print("y <= 10:", y <= 10) # Is 20 less than or equal to 10? -> False
print("x == y :", x == y)  # Is 15 equal to 20? -> False
print("x != y :", x != y)  # Is 15 not equal to 20? -> True

A Complete Integrated Example: app.py

Bringing user input, arithmetic, type conversion, and comparison together

Save the following code as app.py in Linux to see how all these pieces seamlessly connect into a real program:

app.py 
# Ask for user information
name = input("Enter your name: ")
birth_year = int(input("Enter your birth year: "))

# Calculation
current_year = 2026
age = current_year - birth_year

# Comparison check
is_adult = age >= 18

# Display results
print("\n--- Summary ---")
print("Name:", name, "| Data Type:", type(name))
print("Age:", age, "| Data Type:", type(age))
print("Eligible adult (age >= 18):", is_adult)

Run it in your Linux Terminal:

user@linux:~$ python3 app.py
