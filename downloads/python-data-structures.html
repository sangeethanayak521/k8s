Simple Variables (Single-Value Containers)

Holds exactly one piece of information at a time; new assignments overwrite the old value

The 4 Core Primitive Types

A simple variable holds just one value. If you put a new value inside, the previous data is discarded:

int (Integer): Whole numbers
count = 5
float (Decimal numbers)
price = 12.50
str (Words / text)
name = "Ravi"
bool (True or False)
is_logged_in = True
📦 Overwriting Rule: When you execute age = 17 after age = 16, memory slot age replaces 16 with 17 permanently!
simple_vars.py 
# Simple variables holding one value each
student_name = "Priya"
age = 16
height_meters = 1.65
has_passed = True

print(student_name)
print(age)
print(height_meters)
print(has_passed)

# Overwriting a simple variable
age = 17  # The old value (16) is replaced by 17
print("Updated age:", age)
Terminal Output:
Priya
16
1.65
True
Updated age: 17

lists_demo.py 
# Creating a list of fruits
fruits = ["Apple", "Banana", "Mango", "Orange"]

# 1. Reading items using index numbers (starts at 0)
print("First fruit:", fruits[0])   # Apple
print("Second fruit:", fruits[1])  # Banana
print("Last fruit:", fruits[-1])   # Orange (from back)

# 2. Changing an item (Mutable)
fruits[1] = "Blueberry"
print("After updating:", fruits)

# 3. Adding a new item with .append()
fruits.append("Pineapple")
print("After append:", fruits)

# 4. Removing an item with .remove()
fruits.remove("Mango")
print("After removing Mango:", fruits)

# 5. Counting items with len()
print("Total fruits in list:", len(fruits))

Key takeaway: Lists preserve exact insertion order and permit repeated items anytime.

Tuples (tuple): Ordered but Unchangeable

Permanent data sealed in an envelope with permanent marker

🔒 Immutable (Locked) Round Brackets ( )

Why Lock Data in a Tuple?

A Tuple is identical to a list in how you read it with zero-based index numbers [0], but once created, it is permanently frozen. You cannot add, remove, or modify items.

📍 GPS Coordinates: Latitude and longitude should never drift.
🗓️ Days of the Week: Mon-Sun never changes in structure.
🖥️ Screen Resolutions: (1920, 1080) fixed dimensions.
❌ TypeError: Running location[0] = 13.0 throws:
TypeError: 'tuple' object does not support item assignment
tuple_demo.py 
# GPS coordinates of a place: (Latitude, Longitude)
location = (12.9716, 77.5946)

# Reading from a tuple works just like a list
print("Latitude:", location[0])
print("Longitude:", location[1])

# This would cause an ERROR because tuples cannot change:
# location[0] = 13.0000
Terminal Output:
Latitude: 12.9716
Longitude: 77.5946

Dictionaries (dict): Key-Value Pairs

Like a real phonebook or ID card where descriptive labels point to values

dict_demo.py 
# Student record using a dictionary
student = {
    "name": "Kiran",
    "grade": "10th",
    "marks": 92,
    "is_present": True
}

# 1. Looking up values using the key name
print("Student name:", student["name"])
print("Marks:", student["marks"])

# 2. Adding a new key-value pair
student["email"] = "kiran@example.com"

# 3. Changing an existing value
student["marks"] = 95

# 4. Deleting a key-value pair with del
del student["is_present"]

print("Updated student profile:", student)
📇 Live Dictionary Key-Value Inspector

Instead of memorizing positions (0, 1), you access data directly by name:

student["name"] "Kiran"
student["grade"] "10th"
student["marks"] 95 (updated)
student["email"] "kiran@example.com" (new)
student["is_present"] Deleted via del
Rule: Keys must be completely unique. Reassigning to an existing key replaces its value!
5

Sets (set): Unique & Unordered

A magic collection bag where duplicate items are automatically thrown away

✨ Zero Duplicates Allowed Curly Brackets { }

How Sets Behave

A Set stores single items separated by commas inside curly brackets (no colons). Because items have no index numbers, you cannot do colors[0].

1. Instant De-duplication: If you feed {"Red", "Blue", "Green", "Red"}, Python discards the second "Red" automatically.
2. Adding items: Use .add("Yellow"). Adding an already existing item does nothing!
3. Lightning fast lookup: Use "Green" in colors to check membership with O(1) performance.
set_demo.py 
# Notice that "Red" appears twice
colors = {"Red", "Blue", "Green", "Red"}

# Python removes the duplicate automatically
print("Unique colors:", colors)

# Adding an item
colors.add("Yellow")

# Trying to add an existing item changes nothing
colors.add("Blue")
print("After adding colors:", colors)

# Checking if an item is inside using 'in'
print("Is Green in the set?", "Green" in colors)
Terminal Output:
Unique colors: {'Red', 'Blue', 'Green'}
After adding colors: {'Red', 'Blue', 'Green', 'Yellow'}
Is Green in the set? True

Comparison Matrix: Which One To Choose?

At-a-glance cheat sheet to pick the exact right data structure every time

Type Brackets Ordered? Can Change? (Mutable) Duplicates? Best Used For
List [ ] Yes Yes (Mutable) Yes Ordered collections (shopping carts, task lists)
Tuple ( ) Yes No (Immutable) Yes Fixed data that must stay protected (GPS, resolutions)
Dictionary {key: val} Yes* Yes (Values mutable) Keys: No / Values: Yes Labeled records (user profiles, database rows)
Set { } No Yes No (Unique only) Tracking unique items, removing duplicates fast

*Note: Dictionaries maintain insertion order in modern Python versions (3.7+).

Complete Program: Combining All Types Together

How real-world software combines variables, lists, tuples, dicts, and sets into one cohesive system

Save this code in a file named classroom.py to see how all 5 container types work together:

classroom.py 
# 1. Simple variables
class_room_id = 101
teacher_name = "Mr. Sharma"

# 2. List (list of student names)
students_list = ["Amit", "Sneha", "Rahul"]

# 3. Tuple (fixed school timings: start hour, end hour)
school_hours = (9, 16)

# 4. Dictionary (detailed info about one student)
top_student = {
    "name": "Sneha",
    "roll_no": 12,
    "subjects": ["Math", "Science", "English"]  # A list inside a dictionary!
}

# 5. Set (unique club activities available - duplicate "Art" is auto-removed)
clubs = {"Robotics", "Art", "Chess", "Art"}

# Displaying the data
print("=== School Room", class_room_id, "===")
print("Teacher:", teacher_name)
print("Class Timings:", school_hours[0], "AM to", school_hours[1] - 12, "PM")
print("Total Students Registered:", len(students_list))
print("First Student on the Roll:", students_list[0])
print("Topper Name:", top_student["name"], "| Top Subject:", top_student["subjects"][0])
print("Available Clubs (No duplicates):", clubs)

Run in Linux Terminal:

user@linux:~$ python3 classroom.py
